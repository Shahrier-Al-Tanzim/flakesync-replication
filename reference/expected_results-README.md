slug,sha,module,testname,critical-point,barrier-point,threshold,runtime
slug represents project name
sha is the commit of the project
module represents when the test is located
critical-point is used for knowing the boundary location that makes the test fail
barrier-point is used for enforcing the synchronization
threshold is used represents the number of times waiting is required at the barrier point to complete the execution of the critical point), and the duration taken to reach the barrier point for a specified critical point. 
Finally, runtime means the time to get the barrier-point.
